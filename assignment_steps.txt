FACTS FOR README
----------------
- TinyLlama (int8): 3921 nodes / 4492 edges; after constant hiding ~2352
  nodes (0.003 s). Stateful: 44 ReadValue/Assign pairs, 1 Result.
- Own node ids: OpenVINO get_instance_id() is process-global, XML layer ids
  are not exposed by read_model.
- topological_sort = reverse Kahn with FIFO -> layered order by longest path
  to a sink (height never increases along the order). With forward Kahn the
  356 weight Convert sources pulled parts of all 22 layers into the first
  N nodes; now N=1200 keeps layers 0-10.
- Passes work in place on the IR (no graph copies).
- dot profiling: 1200 nodes ~1.1 s; 1500 nodes ~77 s (network simplex in
  position phase; long edges from shared inputs + edge labels double ranks).
  nslimit=2 + splines=line: ~4 s (~19x). nslimit alone or splines alone
  do not help.
- ProxyPass on TinyLlama (threshold 3): 7 nodes marked (shared attention
  inputs); depth ~811 -> ~798 ranks, median width ~180 -> ~103.
- Parser tests save with compress_to_fp16=False, otherwise save_model
  inserts Constant(f16) -> Convert and the graph differs from the built one.
